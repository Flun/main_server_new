설치 방법

1. chrome://extensions 를 엽니다.
2. 우측 상단의 개발자 모드를 켭니다.
3. "압축해제된 확장 프로그램을 로드합니다"를 누릅니다.
4. C:\main_server\chrome_instagram_cookie_bridge 폴더를 선택합니다.
5. Chrome에서 Instagram에 로그인한 상태로 확장 아이콘을 누릅니다.
6. "현재 Chrome 쿠키를 서버에 동기화"를 누릅니다.

이 확장은 instagram.com 쿠키만 127.0.0.1:8999 의 서버 공용 저장소로 전송합니다.
동기화된 쿠키는 모든 데이터셋의 Instagram 수집에서 함께 사용됩니다.
